# Contributing

## Development

1. Fork the repository and create a focused branch.
2. Copy `.env.example` to `.env`.
3. Run `npm install` and `npm run dev`.
4. Add or update tests for behavior changes.
5. Run `npm run check` before opening a pull request.

Use conventional commit prefixes such as `feat:`, `fix:`, `test:`, `docs:`, and `chore:`. Keep user-facing copy concise and keep keyboard access equivalent to pointer access.

## Pull requests

Explain user impact, include test coverage, and call out storage or deployment changes. Do not commit credentials, `.env`, local data, or anything under `/docs/`.
